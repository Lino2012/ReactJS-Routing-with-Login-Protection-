The Secret Ingredient - Recipe Book App 🍳
A beautiful, responsive React.js recipe application with user authentication, favorite recipes, and a modern cooking experience.

Features ✨
🍳 Recipe Discovery - Browse beautiful recipe cards with ratings and descriptions

🔐 User Authentication - Secure login/signup with JWT tokens

❤️ Favorite Recipes - Save and manage your favorite recipes

📱 Responsive Design - Works perfectly on desktop, tablet, and mobile

🎨 Beautiful UI - Playful design with Fredoka One font and warm color scheme

🔍 Search Functionality - Find recipes by name or ingredients

👤 User Profiles - Personal profile with cooking preferences and favorites

Tech Stack 🛠️
Frontend
React.js - Modern React with hooks and functional components

React Router - Client-side routing

CSS3 - Custom responsive styling

Context API - State management for auth and favorites

Backend
JSON Server - Mock REST API with custom middleware

JWT - JSON Web Tokens for authentication

bcryptjs - Password hashing and verification

RESTful API - Clean API endpoints
